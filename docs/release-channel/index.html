Instalacja

  1. 01Otwórz DMG i przeciągnij Switch Commit.app do Aplikacji.
  2. 02Wyrzuć DMG do Kosza po instalacji.
  3. 03Uruchom — ikona pojawi się na pasku menu.
  4. 04Aktualizacje: Settings → Check for Updates.

macOS blokuje pierwsze uruchomienie? Zamknij dialog, w Finderze kliknij appkę prawym przyciskiem → Open → potwierdź Open. Wydanie nie jest jeszcze notarized przez Apple.
